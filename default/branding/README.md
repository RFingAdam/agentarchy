# Branding assets

Generated by `bin/oal-dev-make-branding`. Regenerate rather than hand-edit -- the script holds the
mark's geometry as coordinates, and it emits `mark.svg` and every PNG from that one list so they
cannot drift apart.

```bash
bin/oal-dev-make-branding                    # white, into default/branding
bin/oal-dev-make-branding --colour '#f0a04b' # in the default theme's accent, for a README header
```

| File | What reads it |
|---|---|
| `mark.svg` | the web, READMEs, anything that can rasterise SVG itself |
| `mark.png` | 512 px, transparent -- favicons and anywhere the mark stands alone |
| `logo.png` | the stacked lockup; copied byte-for-byte to `default/plymouth/logo.png` |
| `logo.txt` | the terminal wordmark, read by `bin/oal-show-logo` |

## The mark

An **A with a flat top**. A pointed A is a mountain, which is Arch's and not ours to borrow;
flattening the apex turns the same letter into an arch -- a span on two legs with a crossbar, which
is the word the project is named after. No serif, gradient or shadow, so nothing is lost between a
16 px favicon and the boot splash.

The lockup stacks the mark above the wordmark rather than setting them on one baseline. The word
begins with the same letter the mark is, and side by side it reads as "A agentarchy" -- the mark
stops being a mark and becomes a stutter.

## Two things worth knowing before editing

**SVG does not rasterise here.** ImageMagick's librsvg delegate shells out to `rsvg-convert`, which
is not installed, and the internal MSVG renderer silently draws nothing for a stroked path -- you get
a blank PNG with one colour in it and no error. That is why the PNGs are drawn with `-draw`
primitives and the SVG is emitted alongside, rather than one being rasterised from the other.

**The greeter has no image assets at all.** It draws its wordmark as palette-coloured text, so
`default/sddm/oal/logo.png` no longer exists. Nothing in `default/sddm/oal/` should ever be an
image again; `test/unit/theme-surface.bats` fails if one appears.

`logo.txt` is still written by hand in half-block characters, so it renders in any monospace font
without needing a Nerd Font glyph.
