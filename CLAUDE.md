# Agentarchy -- instructions for Claude Code

Read first: `docs/superpowers/specs/2026-08-22-agentarchy-design.md` (approved design) and
`tasks/todo.md`. Both are gitignored working notes -- present in a working checkout, absent from a
fresh clone. If they are not there, the git log and `docs/` carry the decisions instead.

## Naming (non-negotiable)
- Project/package/install root: `agentarchy`, `/usr/share/agentarchy`.
- Everything a user types or sees in a terminal: `oal` -- commands `oal-*`, env `OAL_*`,
  `~/.config/oal`, `~/.local/state/oal`, `~/.local/share/oal`.
- The word `omarchy` may appear only under `upstream/`, `docs/`, `tasks/`, `test/fixtures/`,
  `test/unit/`, `.github/`, and in `NOTICE`, `LICENSE`, `README.md`, `CLAUDE.md`, `AGENTS.md`
  (plus the gitignored scratch trees `.sync/` and `.superpowers/`). `bin/oal-dev-branding-check`
  enforces exactly that list, over file contents **and** tracked file names.

## Vendored code
- **Ownership is `upstream/VENDORED-FILES.txt`**, not the manifest: it lists every path
  `bin/oal-dev-sync-upstream` writes. A file listed there is never hand-edited -- change a data file
  under `upstream/` and re-run `--apply`, or capture the edit with `bin/oal-dev-upstream-patch`
  (patches apply with no fuzz). A file *not* listed there is native and yours to edit.
- Inputs: `VENDOR-MANIFEST` (globs over **upstream** paths, later lines win), `RENAME-PATHS.sed`
  (path renames), `RENAME-MAP.sed` (content rewrites), `EXCLUDE-BIN.regex` + `FORCE-INCLUDE-BIN`
  (`bin/` triage), `NEEDS-PORT.regex`, `patches/`.
- Reports, regenerated by `--apply` and checked by `--check`: `VENDORED-FILES.txt`,
  `EXCLUDED-BIN.txt` (upstream paths), `NEEDS-PORT.txt`, `DANGLING.txt`. `EXCLUDED-ASSETS.md` is
  hand-kept: excluded images and other non-scripts that vendored files still reference.
- Never vendor `shell/`, `config/hypr`, `default/hypr`, `default/uwsm`, or branding assets -- and
  "never" means an `exclude` line in `VENDOR-MANIFEST`, since every gate is text-based and none of
  them can see inside an image.
- Full contract and the PIN-bump runbook: **`upstream/README.md`**.

## Workflow
- Plan mode for anything non-trivial; keep `tasks/todo.md` current; record corrections in
  `tasks/lessons.md`. Neither is committed, so anything a contributor needs belongs in the commit
  message, `docs/`, or a comment next to the code.
- Before claiming done: `bin/oal-dev-check` must pass (eight `PASS` lines); paste its output in the PR.
- Owner-actions (things only Adam can do) go under the "Owner-actions" heading in `tasks/todo.md`.
- Shell: `#!/usr/bin/env bash`, `set -euo pipefail`, shellcheck clean. Tests: bats under `test/unit`.
- Commits: conventional prefixes, no AI co-author trailers.
